## 🛠️ Features

Sketchetc includes several tools to help your workflow.

### Clipboard History
The clipboard tool saves the text and images you copy. Press the configured hotkey to see a list of your previous clips. Select any item to paste it into your current document. This feature saves you time when you move data between apps.

### System Monitor
The monitor displays your hardware usage. It shows information about your memory, processor load, and network speed. Keep this widget visible to watch your system performance in real time.

### Tamper-Proof Journal
Keep your notes secure with the built-in journal. The app encrypts your entries to ensure you remain the only person with access. It supports basic text formatting and date stamping.

### Window Snapping
Organize your open windows with the snap tool. Drag a window to the edge of your screen to resize it automatically. This fills half of your display, letting you view two programs side by side.

### Aura Points
Track your productivity with the aura points system. This feature rewards you for completing tasks and maintaining your workflow. It gamifies your digital habits to encourage focus and discipline.

## ℹ️ Troubleshooting

If the program fails to open, check the following points:

1. Restart your computer. This clears temporary issues that stop software from loading.
2. Verify that you extracted all files from the download folder if you chose the zip version.
3. Check your antivirus settings. Sometimes security software blocks new programs. Allow the program to run in your security dashboard.
4. Ensure your Windows system has the latest updates. Old systems sometimes lack the features required by modern software.
